## 边界

raw 使用原单位直接差值除以查询联合 AC 范数；shape 使用 float64 稳定的逐通道时间去均值、两通道联合 unit L2，只允许逐通道 DC offset 和联合正 scale。点积仅用于形状初筛，所有可能的块内最近邻及阈值候选以直接差值重算，精确计算距离并列时选最小原始参考索引。零 AC 查询两个距离均不适用，零 AC 参考只从 shape 中排除。

独立 CLI 沿用 PreparedDataset 缓存协议，但只校验并映射 train/validation，避免其三集合初始化读取 test 信号；实际校验范围为冻结 summary、选定 manifests、选定 cache x/y 字节及标签行序。原始来源 SHA 继承自所绑定的 prepare metadata，本次未重新读取原始文件或 test 信号。

阈值内候选为 0 只说明当前下采样缓存、两种距离及固定阈值下未发现候选；不能证明实际采集来源独立，不能排除时间平移、裁剪、符号变换或其他未定义形式的相似/泄漏。形状相近本身也不判定泄漏。本诊断不计算 test 分类指标，也不改变划分或缓存。
