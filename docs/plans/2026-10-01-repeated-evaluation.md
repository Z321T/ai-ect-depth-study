# 下一单元：固定噪声重复评价与测试执行

前提：formal_v1九项完整训练/权重/预测已验收，registry保持不可变。SVM当前干净验证优于网络，不能据此修改已登记对照、删seed或覆盖运行。类别语义未确认，仍只用class_index。

1. 实现独立评价入口，接收registry、split=validation/test和新输出目录；不重训、不选epoch/候选、不拟合Scaler或标准化统计量。SVM重载固定Pipeline，深度重载保存权重并配置与训练相同的确定性/TF32开关。GPU用可访问执行上下文，支持cpu/cuda/auto，不再评估资源。
2. 在评价前核验登记配置、九报告/源码/缓存/manifest及SVM报告/必需产物SHA、无失败marker。validation使用noise10–14、namespace=validation；test使用100–104、namespace=test。Clean仅一次，30/20/10dB每个seed各一次，同一wave/条件/seed跨模型共享原单位AC扰动，随后使用各既定预处理。恒定信号保留并明确SNR不适用。
3. 针对封存test不被默认访问、严格新目录/失败处理、固定权重与标签/身份/行序核验、扰动跨模型一致、Clean不重复及汇总层次，编写必要回归测试。validate-only接口只推理validation；完整身份哈希/mmap按现有读取器范围允许，不冒充“完全未读取test文件”。
4. 输出完整身份/条件/训练seed/noise seed/预测CSV，Accuracy、Macro-F1、每类召回/混淆矩阵和名义连接组表现。每训练seed先汇总五个噪声重复，再计算三训练seed均值/样本SD；单列噪声波动，SVM单确定性模型不伪造训练seed重复。固定split波动不作采集总体CI。
5. 先执行全部模型validation固定重复，独立逐条重载核验及CSV计数重算、汇总统计和图验收，更新状态。不能据这个后评估更换formal_v1权重。任何新训练规则另立探索性协议和目录，保持最终测试门槛。
6. 评价实现通过测试与独立复核后，记录正式test释放门槛已满足，按冻结协议一次执行4800条test分类及固定噪声重复；所有失败按原配置/新目录重试并留记录，不能据test分数调参。完成完整报告并明确公开数据重复、实际来源和单试件的外推边界。

增强/普通ResNet同时改变训练噪声与模型选择目标，报告为整体流程比较；不得作噪声单因素因果声明。时间目标服从阶段门槛，原始数据/缓存/权重不提交公开仓库；可提交公开MDDECT派生的预测/指标/图及来源说明。
